# 🦀 Rust TUI Editor

Современный текстовый редактор с графическим интерфейсом в терминале, написанный на Rust с использованием библиотеки `ratatui`.

## ✨ Особенности

- 🎨 **Современный дизайн**: Тёмная цветовая схема с акцентными цветами для различных элементов интерфейса
- 📑 **Вкладки**: Удобное переключение между открытыми файлами с индикатором изменений (●)
- 📁 **Дерево файлов**: Навигация по проекту с эмодзи-иконками (📁 папки, 📄 файлы)
- ⌨️ **Палитра команд**: Быстрый доступ к командам через `Ctrl+P` с динамической подсветкой
- 📊 **Строка статуса**: Отображение режима (NORMAL, INSERT, CMD), позиции курсора, кодировки и типа файла
- 🚀 **Производительность**: Написан на Rust для максимальной скорости и низкого потребления памяти

## 🛠️ Требования

- Rust (последняя стабильная версия)
- Cargo
- Терминал с поддержкой Unicode и true color (рекомендуется)

## 🚀 Установка и запуск

### Клонирование репозитория

```bash
git clone <repository-url>
cd <repository-directory>
```

### Сборка проекта

```bash
cargo build --release
```

### Запуск

```bash
cargo run
```

Или используйте собранный бинарник:

```bash
./target/release/rust-tui-editor
```

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `hjkl` / Стрелки | Навигация |
| `Enter` | Открыть файл / Выбрать команду |
| `Esc` | Выйти из режима / Закрыть палитру |
| `Ctrl+P` | Открыть палитру команд |
| `Ctrl+S` | Сохранить файл |
| `Ctrl+Q` | Выход |
| `i` | Режим вставки (INSERT) |
| `:` | Режим командной строки |
| `/` | Поиск |
| `Ctrl+N` / `Ctrl+T` | Новое окно / Дерево файлов |

## 🎨 Цветовая схема

Редактор использует современную тёмную палитру с следующими акцентами:

- **NORMAL**: 🟢 Зеленый
- **INSERT**: 🔵 Синий
- **CMD**: 🟠 Оранжевый
- **SEARCH**: 🟡 Желтый
- **TREE**: 🟣 Фиолетовый
- **TERM**: 🩷 Розовый
